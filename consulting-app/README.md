# SIP·Consulting

Código de la página https://sipartners.com.mx/consulting/ (Next.js + Tailwind, exportada como sitio estático).

- Para trabajar en local: `npm install` y `npm run dev`.
- No edites la carpeta `consulting/` de la raíz del repo: la genera sola la acción **Publicar Consulting** cada vez que cambia algo en esta carpeta y se hace merge a `main`.
